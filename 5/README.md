# Game 5 to the top

A platform game where the player has to ascend from the bottom to the top using the ramps and special objects. The ramps randomly have ladders, chutes, stairs, and boxes, for ascending. The game theme is wild west themed, so items drop from the top, and roll down the ramps until they reach the bottom and disappear offscreen. These items cause damage to the user, so the user needs to jump or ascend to avoid them. There are gaps in the ramps that the user needs to jump over, that the items fall through. When the player gets to the top platform, there is a button the player walks into that starts a new randomized level.
