# Game Land of Simplex (game 6)

A procedurally generated RPG, based on Simplex noise generation, top-down

## Details

Player:

- can walk and run up, down, left, right, as well as diagonally
- can weild a sword, swing and parry
- can fall in puts, climb up ladders

Inventory:

- can hold 8 items in inventory
- can hold up to 1 weapon (sword, knife), and 1 sheild
- can accumlate up to 255 coins

Objects:

- doors
